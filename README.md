# Mirath (مِرث) — Ancient World Games & Open Heritage Analytics

Mirath is an advanced Android application built with Kotlin and Jetpack Compose that explores and simulates forgotten ancient board games based on archaeological research and cuneiform tablets (such as The Royal Game of Ur, Egyptian Senet, Abbasid Shatranj, Viking Hnefatafl, Seega, and Omani Hawalis).

## Features
- **Curatorial Home Dashboard**: KPI specimen cards, documented artifacts counter, and live simulator stats.
- **Games Catalog**: Search and filter historical board games by civilization and era.
- **Interactive Board Game Simulator**: Playable simulation of ancient board games with pyramidal dice rolling, Rosette bonus tiles, and move tracking.
- **Interactive Map**: Civilizational and geographic distribution of archaeological game boards across 6 major regions.
- **Articles & Learn Center**: Scholarly articles and research papers on ancient game rules and history.
- **Open Heritage Analytics**: Quantitative insights, match statistics, and probability models.
